# Ebook Buddy

Ebook Buddy is a desktop application for reading ebooks with integrated AI chat functionality.

## Features

- PDF reading with smooth page navigation
- AI chat with image and voice support
- Voice input (Alt+Click to record)
- Clipboard image paste support
- Page image capture for AI chat (right-click on PDF page)
- Multi-image selection for AI chat (up to 10 images)
- Secure API key storage
- Markdown rendering with LaTeX support

## Tech Stack

- Electron 28
- React 18
- TypeScript 5.3
- Zustand (state management)
- MUI (UI components)
- PDF.js (PDF rendering)

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build for development (unpacked)
npm run build:pack

# Build for distribution (installer)
npm run build:dist
```
